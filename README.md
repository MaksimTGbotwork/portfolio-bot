# Portfolio Bot

Telegram-бот на aiogram 3, демонстрирующий ключевые механики для клиентских проектов.

## Стек
- Python 3.13
- aiogram 3.29
- aiosqlite (хранение данных)
- python-dotenv
- Деплой: Railway

## Функции
- Регистрация с сохранением в БД (FSM-анкета)
- Приём оплаты через Telegram Stars
- Обработка фото, видео, документов, анимаций
- Инлайн и обычные клавиатуры

## Команды
- /start, /help, /about
- /User — заполнить анкету
- /myprofile — посмотреть свой профиль
- /pay — оплата подписки
- /file — получить тестовый файл

## Запуск локально
1. Клонировать репозиторий
2. `pip install -r requirements.txt`
3. Создать `.env` с `BOT_TOKEN=твой_токен`
4. `python main.py`
